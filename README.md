# Portfolio

Personal portfolio page of Muhamad Zolfahmizal Mohamad Khairudin. Plain HTML, no build step.

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 5173
```

Interactive effects use [Sakuga VFX](https://github.com/finktheartist/sakuga-vfx) (MIT, see `vendor/LICENSE`).

## Branch `scroll-version`

A cinematic scroll-driven version: smooth scroll (Lenis), scroll animations and a pinned sideways project ride (GSAP ScrollTrigger), and a water level that rises as you scroll, read by a 4-level gauge (a nod to the AquaAlert project). Motion turns off for `prefers-reduced-motion`. Libraries are vendored in `vendor/scroll/` (GSAP standard no-charge licence, Lenis MIT).
