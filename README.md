# Portfolio

Personal portfolio page of Muhamad Zolfahmizal Mohamad Khairudin. Plain HTML, no build step.

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 5173
```

Interactive effects use [Sakuga VFX](https://github.com/finktheartist/sakuga-vfx) (MIT, see `vendor/LICENSE`).
